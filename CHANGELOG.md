# Changelog

## 0.1.0

- Combined Spotlight filenames and folders with local DigUp content search.
- Added previews, file type filters, recent files and Finder/clipboard actions.
- Preserved matched media timestamps, PDF search text and editor line numbers through DigUp.
- Added a native warm search bridge compatible with Tinycast's subprocess API.
- Added standalone builds from pinned DigUp source, CI and portable Tinycast release ZIPs.
